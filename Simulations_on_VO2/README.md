# July 2026 presentation archive

This directory preserves the source, compiled PDF, figures, and animations for the
July 2026 project presentation. `main.tex` is the editable Beamer source and `main.pdf`
is the compiled deck used at that time.

The deck is a historical presentation snapshot, not the current quantitative model
authority. The August 2026 solver and calibration audit added exact frozen-coefficient
electrical/thermal substeps, a true `C=0` algebraic limit, corrected hysteresis endpoint
handling, and new lab-calibration evidence. See `docs/CURRENT_DRIVE_CALIBRATION.md` and
`docs/figures/current_drive/` for those current results.
