# Project references

- `experimental_manuscript.pdf`: Gildor et al., [arXiv:2604.04594v1](https://arxiv.org/abs/2604.04594v1),
  the experimental TIA manuscript. Its canonical local copy is
  `references/papers/gildor2026_arxiv_2604.04594v1.pdf` (SHA-256
  `cad51f0274a39a4cb08425c5c3ceca31945fa73c4e6afb52097fb6f029bfa1cc`).
  The PDF is an unmodified copy of the authors' 6 April 2026 preprint, shared
  under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- `almeida_hysteresis_model.pdf`: Almeida et al. (2002), the static VO₂
  hysteresis model. The previous `experimental_manuscript.pdf` link mistakenly
  targeted this unrelated paper; that link was corrected on 18 September 2026.
- `yuanhang_collective_dynamics.pdf`: Zhang et al. reference paper behind the original
  neuristor model.
- `yuanhang_original_implementation/`: preserved upstream implementation used for
  fidelity comparisons.

These entries point to the repository's canonical reference copies.
