# Published bundles: preserved local evidence

Each dated folder is a complete preserved result bundle. Open the
[artifact library](../artifacts/index.html) to search them by workflow and status.
Do not edit a completed bundle in place; run and publish a new one.

`neuristor runs publish RUN_ID` copies an eligible local bundle here. It does not
commit, push to GitHub, or declare that a parameter fit is experimentally correct.

New sample-study maps embed GIFs inside `parameter_maps.html`. Older map exports
may require their adjacent GIFs folder; inspect their report before sharing.
Raw numerical tables and reports are more authoritative than animations.
